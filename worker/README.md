# Υπηρεσία «Άλλαξέ το» (Cloudflare Worker)

Όταν ο τεχνίτης πατά «Άλλαξέ το» σε ένα βήμα της ανάλυσης εργασιών, η εφαρμογή στέλνει εδώ το κείμενο της ανάλυσης,
το σημείο που διάλεξε, τις απαντήσεις του («Τι δεν σου αρέσει;», «Πώς το θέλεις;») και τους κανόνες ύφους του. Ο worker
ρωτά το Claude (Anthropic) και επιστρέφει μόνο τη νέα εκδοχή εκείνου του σημείου.

Γιατί χρειάζεται: το κλειδί του Anthropic API **δεν μπαίνει ποτέ** στην εφαρμογή, στον browser ή στο repo. Το κρατά μόνο
ο worker, ως κρυπτογραφημένο secret του Cloudflare.

Το PDF της ανάλυσης δεν χρειάζεται τον worker: βγαίνει από τις έτοιμες αναλύσεις, και χωρίς σύνδεση.

## Τι χρειάζεσαι

- Λογαριασμό **Cloudflare** (το δωρεάν πλάνο φτάνει, χωρίς κάρτα): <https://dash.cloudflare.com/sign-up>
- Κλειδί **Anthropic API**: <https://console.anthropic.com/settings/keys>. Χρεώνεται ανά χρήση, με προπληρωμένα
  credits (εκτίμηση κόστους πιο κάτω).
- **Node.js 20** ή νεότερο στον υπολογιστή σου.

## Εγκατάσταση, βήμα βήμα (μία φορά)

Όλες οι εντολές τρέχουν μέσα στον φάκελο `worker/`.

1. Εγκατάσταση των εργαλείων:

   ```bash
   cd worker
   npm install
   ```

2. Σύνδεση στο Cloudflare (ανοίγει ο browser, πατάς «Allow»):

   ```bash
   npx wrangler login
   ```

3. Πρώτο deploy:

   ```bash
   npx wrangler deploy
   ```

   Αν ο λογαριασμός δεν έχει ακόμα subdomain `workers.dev`, το wrangler σε ρωτά ένα όνομα (π.χ. `ergolav`). Στο τέλος
   γράφει τη διεύθυνση του worker, π.χ. `https://ergolav-rewrite.ergolav.workers.dev`. Κράτα την.

4. Το κλειδί του Anthropic, ως secret (το επικολλάς όταν σου το ζητήσει· δεν φαίνεται και δεν γράφεται σε αρχείο):

   ```bash
   npx wrangler secret put ANTHROPIC_API_KEY
   ```

5. Έλεγχος ότι απαντά μόνο στην εφαρμογή (πρέπει να δεις `HTTP/2 204` και `access-control-allow-origin`):

   ```bash
   curl -i -X OPTIONS https://ergolav-rewrite.ergolav.workers.dev/rewrite-section -H 'Origin: https://aggelosemiris.github.io' -H 'Access-Control-Request-Method: POST'
   ```

   Με άλλο `Origin` πρέπει να δεις `403`.

6. Η διεύθυνση στην εφαρμογή: στο `src/config.js` γράψε

   ```js
   export const REWRITE_URL = 'https://ergolav-rewrite.ergolav.workers.dev/rewrite-section';
   ```

   (με το δικό σου subdomain). Προαιρετικά, στο `index.html` στένεψε το `connect-src` της CSP από
   `https://*.workers.dev` στη δική σου διεύθυνση.

7. Το `src/config.js` ανεβαίνει με το επόμενο push στο `lab`, που είναι και το deploy της εφαρμογής (GitHub Pages).
   Μόνο μετά από έγκριση.

Από εκεί και πέρα, κάθε αλλαγή στον worker ανεβαίνει με `npx wrangler deploy`.

## Ρυθμίσεις (`wrangler.toml`, ενότητα `[vars]`)

| Ρύθμιση | Προεπιλογή | Τι κάνει |
|---|---|---|
| `ALLOWED_ORIGIN` | `https://aggelosemiris.github.io` | Από πού δέχεται αιτήματα (CORS). Πολλά, με κόμμα. |
| `MODEL` | `claude-opus-5-5` | Το μοντέλο του Claude. |
| `EFFORT` | `low` | Πόσο «σκέφτεται» το μοντέλο. Το `low` κρατά τη διόρθωση γρήγορη. |
| `RATE_DEVICE_PER_HOUR` | `30` | Αιτήματα ανά συσκευή την ώρα. |
| `RATE_IP_PER_HOUR` | `60` | Αιτήματα ανά IP την ώρα (π.χ. όταν κάποιος αλλάζει το αναγνωριστικό συσκευής). |
| `RATE_GLOBAL_PER_DAY` | `300` | Όλα τα αιτήματα την ημέρα: ανώτατο όριο κόστους. |
| `FALLBACKS` | (κενό) | `off` = χωρίς server-side fallback σε άλλο μοντέλο όταν το Claude αρνηθεί. |
| `TIMEOUT_MS` | `25000` | Μέγιστος χρόνος αναμονής για την απάντηση του AI. |

Μετά από αλλαγή: `npx wrangler deploy`.

## Ασφάλεια και προσωπικά δεδομένα

- **Κλειδί**: μόνο ως secret του Cloudflare. Ο worker δεν το επιστρέφει ποτέ και δεν το γράφει σε logs.
- **CORS**: απαντά μόνο σε αιτήματα από το `ALLOWED_ORIGIN`· όλα τα άλλα παίρνουν `403`. Το `Origin` μπορεί να το
  πλαστογραφήσει πρόγραμμα εκτός browser, γι' αυτό υπάρχουν και τα όρια αιτημάτων.
- **Όρια**: ανά συσκευή (τυχαίο αναγνωριστικό της εφαρμογής, header `X-Device-Id`), ανά IP και συνολικά την ημέρα.
  Η IP δεν αποθηκεύεται ως έχει: μόνο το hash της ορίζει τον μετρητή. Οι μετρητές ζουν σε Durable Objects (SQLite).
- **Μέγεθος**: έως 32 KB ανά αίτημα, έως 500 χαρακτήρες ανά απάντηση του τεχνίτη, έως 20 κανόνες των 200 χαρακτήρων.
  Η ανάλυση που στέλνεται πρέπει να περνά τους κανόνες της Φάσης 4 (`src/analysis-schema.js`).
- **Χρόνος**: 25 δευτερόλεπτα το πολύ· μετά η εφαρμογή δείχνει «Η απάντηση άργησε πολύ». Όλα τα μηνύματα λάθους είναι
  στα ελληνικά.
- **Προσωπικά δεδομένα**: ονόματα, τηλέφωνα και email τα αφαιρεί η εφαρμογή πριν φύγει το αίτημα
  (`src/rewrite-client.js`, `stripPersonal`). Ο worker κάνει δεύτερο πέρασμα για τηλέφωνα, email και «κ./κυρία Όνομα».
- **Logs**: μία γραμμή ανά αίτημα με κατάσταση, χρόνο, tokens και μοντέλο. Ποτέ το κείμενο του αιτήματος ή της απάντησης
  (ούτε το μήνυμα λάθους του JSON parser, που περιέχει κομμάτι του κειμένου).
- **Έλεγχος απάντησης**: η νέα εκδοχή περνά τους ίδιους κανόνες με τις αναλύσεις (καμία εγγύηση, καμία υπόσχεση,
  όρια μήκους και πλήθους). Αν αποτύχει, ο worker ξαναρωτά μία φορά με τα λάθη μέσα στο αίτημα.
- **Γνωστό όριο**: το origin του GitHub Pages (`https://aggelosemiris.github.io`) είναι κοινό για όλα τα repos του
  λογαριασμού. Σελίδα από άλλο repo του ίδιου λογαριασμού περνά τον έλεγχο CORS. Τα όρια αιτημάτων ισχύουν κι εκεί.

## Κόστος (εκτίμηση)

Με `claude-opus-5-5` ($4 ανά εκατομμύριο tokens εισόδου, $20 εξόδου, $0,20 για ανάγνωση από cache):

- system prompt περίπου 2.600 tokens (ίδιο σε κάθε αίτημα, μπαίνει στο prompt cache για 5 λεπτά),
- αίτημα περίπου 1.000–1.400 tokens (η ανάλυση της εργασίας και οι απαντήσεις),
- απάντηση περίπου 300–700 tokens (με τη σύντομη σκέψη του `low`).

Άρα περίπου **$0,02–0,03 ανά διόρθωση** (έως ~$0,06 όταν χρειαστεί δεύτερη προσπάθεια). Με το όριο των 300 αιτημάτων
την ημέρα, το ανώτατο κόστος είναι περίπου $9 την ημέρα. Τα πραγματικά tokens κάθε αιτήματος φαίνονται στα logs του
worker (Cloudflare dashboard → Workers → ergolav-rewrite → Logs).

## Τοπική δοκιμή

```bash
npx wrangler dev
```

Θέλει αρχείο `worker/.dev.vars` (δεν ανεβαίνει στο git) με `ANTHROPIC_API_KEY=...` και
`ALLOWED_ORIGIN=http://127.0.0.1:8087`. Δοκίμασέ τον με `curl`. Για δοκιμή μέσα από την εφαρμογή χρειάζεται προσωρινά
και `http://127.0.0.1:8787` στο `connect-src` της CSP.

Έλεγχος ότι ο κώδικας χτίζεται, χωρίς deploy:

```bash
npm run check
```

## Αν κάτι δεν δουλεύει

| Τι βλέπεις | Τι σημαίνει |
|---|---|
| «Η υπηρεσία «Άλλαξέ το» δεν έχει ρυθμιστεί ακόμα» | Κενό `REWRITE_URL` στο `src/config.js`. |
| «Η υπηρεσία δεν έχει ρυθμιστεί ακόμα» (503) | Λείπει το secret: βήμα 4. |
| `403` | Το `ALLOWED_ORIGIN` δεν ταιριάζει με τη διεύθυνση της εφαρμογής. |
| «Έκανες πολλές αλλαγές σε λίγη ώρα» (429) | Όριο αιτημάτων· ξαναδοκίμασε μετά από όσα λεπτά γράφει. |
| «Η υπηρεσία AI δεν απάντησε» (502) | Πρόβλημα στο Anthropic API (π.χ. λάθος κλειδί ή τελείωσαν τα credits). |
| «Χρειάζεται σύνδεση» | Η συσκευή είναι offline. Το PDF βγαίνει κανονικά. |

## Αρχεία

- `src/handler.js`: η λογική (έλεγχοι, CORS, όρια, χρόνος, logs). Ελέγχεται με τεστ (`test/worker.test.js`).
- `src/prompt.js`: το αίτημα προς το Claude. Τα κείμενα έρχονται από τα `prompts/rewrite.md` και `prompts/analysis.md`
  μέσω του `src/prompt-text.js`, που γράφεται με `npm run prompt`.
- `src/limits.js`: το όριο αιτημάτων (σταθερό παράθυρο).
- `src/index.js`: η είσοδος του worker, με το SDK της Anthropic και το Durable Object των ορίων.
