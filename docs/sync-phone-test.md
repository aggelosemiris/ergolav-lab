# Δοκιμή συγχρονισμού σε 2 πραγματικά κινητά (στόχος 12)

**Πότε:** αφού τρέξει η migration `20261123000000_quotes.sql` (έλεγχος «QUOTES RLS OK») και μπει στο `lab` το PR με
`QUOTES_SYNC_ENABLED = true`. Ο έλεγχος γίνεται πριν το launch, μόνο με **λογαριασμούς δοκιμής** (όχι πραγματικοί πελάτες).

**Συσκευές:** ένα **Android** (Chrome) και ένα **iPhone** (Safari και εικονίδιο στην αρχική οθόνη).
Λογαριασμοί: **Δ1** (ίδιος και στα δύο κινητά) και **Δ2** (για τον έλεγχο «δύο χρήστες στο ίδιο κινητό»).

**Πριν ξεκινήσεις:** στο κινητό, άνοιγμα της εφαρμογής → κλείσιμο → ξανά άνοιγμα, ώστε να έρθει η νέα έκδοση (service worker). Η πτήση
ανοίγει από τα γρήγορα κουμπιά του κινητού.

Συμπληρώνεις ✓ ή ✗ σε κάθε στήλη. Σε ✗, μία γραμμή στη «Σημείωση» με το τι έγινε και, αν γίνεται, screenshot.

| # | Έλεγχος | Τι πρέπει να γίνει | Android | iPhone | Σημείωση |
|---|---|---|---|---|---|
| 1 | Πρώτη σύνδεση με προσφορές | Κινητό με 2–3 προσφορές → σύνδεση Δ1 → Προσφορές: «✓ Συγχρονίστηκε» σε λίγα δευτερόλεπτα. Supabase → `quotes`: ίδιος αριθμός γραμμών, καμία διπλή | | | |
| 2 | Άδειο κινητό | Το άλλο κινητό, σύνδεση Δ1 → εμφανίζονται οι ίδιες προσφορές (πελάτες, σύνολα, ημερομηνίες, κατάσταση). Μία ανοίγει ως PDF | | | |
| 3 | Αριθμός προσφοράς | Νέα προσφορά στο 2ο κινητό → παίρνει τον επόμενο αριθμό, όχι διπλό «Αρ.» | | | |
| 4 | Νέα προσφορά στο άλλο | Γύρνα στο 1ο κινητό (ή κλείσε και άνοιξε την εφαρμογή) → φαίνεται η νέα προσφορά | | | |
| 5 | Ημερολόγιο | Αλλαγή ημερομηνίας και κατάστασης στο ένα → φαίνεται στο άλλο | | | |
| 6 | **Αλλαγή χωρίς σήμα** | Πτήση → αλλαγή κατάστασης μιας προσφοράς → «Θα συγχρονιστεί όταν έχεις σήμα», κανένα σφάλμα. Έξω από την πτήση → «✓ Συγχρονίστηκε» → η αλλαγή φαίνεται στο άλλο | | | |
| 7 | **Σβήσιμο χωρίς σήμα** | Πτήση → σβήσιμο μιας προσφοράς → φεύγει αμέσως. Έξω από την πτήση → φεύγει και από το άλλο κινητό | | | |
| 8 | **Νέα προσφορά χωρίς σήμα** | Πτήση → νέα προσφορά ως PDF → μένει στη λίστα. Έξω από την πτήση → ανεβαίνει και φαίνεται στο άλλο | | | |
| 9 | **Σύγκρουση** | Και τα δύο σε πτήση → η ίδια προσφορά «Κλείστηκε» στο Android, μετά «Χάθηκε» στο iPhone → έξω από την πτήση και τα δύο → και τα δύο δείχνουν «Χάθηκε» (η νεότερη αλλαγή) | | | |
| 10 | Αποσύνδεση με σβήσιμο | Αποσύνδεση με «Σβήσε τις προσφορές από αυτή τη συσκευή» → φεύγουν. Σύνδεση ξανά → ξανάρχονται | | | |
| 11 | Αποσύνδεση με εκκρεμότητα | Σε πτήση, αλλαγή → αποσύνδεση: το μήνυμα λέει ότι κάτι δεν ανέβηκε και το κουτάκι είναι κλειδωμένο | | | |
| 12 | **Δύο χρήστες στο ίδιο κινητό** | Δ1 με προσφορές → αποσύνδεση **χωρίς** σβήσιμο → σύνδεση Δ2 → ημερολόγιο, λίστα, «📋 Προσφορές (0)»: **καμία** προσφορά του Δ1 | | | |
| 13 | Δύο χρήστες: νέα προσφορά | Ο Δ2 φτιάχνει προσφορά → Supabase: η γραμμή ανήκει στον Δ2. Αποσύνδεση → σύνδεση Δ1 → βλέπει μόνο τις δικές του, όχι του Δ2 | | | |
| 14 | Δύο χρήστες: σβήσιμο | Ο Δ2 αποσυνδέεται με «Σβήσε από τη συσκευή» → ο Δ1 συνδέεται → οι προσφορές του Δ1 είναι **όλες** εκεί | | | |
| 15 | iPhone: Safari και αρχική οθόνη | Προσφορά στο Safari (με σύνδεση) → άνοιγμα από την αρχική οθόνη με σύνδεση → η προσφορά είναι εκεί | — | | Ξεχωριστή αποθήκευση στο iPhone |
| 16 | Διαγραφή λογαριασμού | Διαγραφή του Δ2 → Supabase `quotes`: καμία γραμμή του Δ2 | | | |
