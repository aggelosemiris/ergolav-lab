Διαχείριση υπηρεσίας ergolav

Τοπικό εργαστήριο. Ενεργοποίησε την υπηρεσία μία φορά εδώ. Ο τεχνικός δημιουργεί το έξτρα PDF χωρίς να συμπληρώνει key.

Μένει μόνο στη μνήμη του server μέχρι να τον κλείσεις. Δεν γράφεται σε αρχείο ή repo. Ο έλεγχος στέλνει ένα μικρό δοκιμαστικό αίτημα στην επιλεγμένη υπηρεσία και καταναλώνει χρήση API.

Οι μονάδες είναι δοκιμαστικές, χωρίς χρηματική αξία. Δεν έχουν συνδεθεί πραγματικές πληρωμές ή λογαριασμοί πελατών. Αυτή η υπηρεσία λειτουργεί μόνο στον υπολογιστή σου.
